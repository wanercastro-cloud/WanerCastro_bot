# Overnight Telegram Bot

Bot focado em overnight e continuação válida.

## Comandos
- /start
- /ping
- /overnight
- /radar
- /smartmoney

## Railway
Use as variáveis do arquivo `.env.example`.

## Observação
O bot usa `/coins/markets` e `/coins/{id}/market_chart` em intervalo hourly. Isso serve para overnight e radar 1h. Não é feed de scalp.
